# ポン出し (pondashi)

配信の BGM / SE をボタンで再生するローカル Web アプリ。サーバー不要で、ブラウザ (Chrome / Edge) だけで動きます。

## 起動

```sh
npm install
npm run dev   # http://localhost:5180 が開きます
```

## 使い方

- 右下の **＋** で音声ファイルを選んでボタンを追加（複数選択可）
- ボタンを **2 回押し** で再生。再生中のボタンを 2 回押しで停止
- **BGM**: 押すと前の BGM がフェードアウト → 「頭の空白」だけ待って → 頭から再生
- **SE**: BGM を止めずに重ねて再生
- **編集モード**: ドラッグで移動、右下の角でサイズ変更、クリックで詳細設定（表示名・ファイル差し替え・カテゴリ・ループ・音量・頭の空白）
- **設定**: 出力デバイス選択、BGM フェードアウト時間
- **Esc** で全停止

## データの保存場所

- ボタン配置・設定: `localStorage`
- 音声ファイル本体: `IndexedDB`（追加時にブラウザ内へコピー）

どちらもブラウザ・オリジン (`localhost:5180`) ごとの保存です。ポートやブラウザを変えると別データになります。

## 出力デバイスについて

`AudioContext.setSinkId` を使用しています（Chrome / Edge 110+）。
Chrome はマイク許可がないとデバイス名を返さないため、設定画面の「デバイス一覧を取得（マイク許可）」を一度押してください。
